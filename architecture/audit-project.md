# NexusTask — AuditProject Entity Specification

**Audit engagement with multi-dimensional health scoring**

---

## Purpose

An **audit project** represents a single data quality assessment engagement for a Company. It encapsulates the data source, scoring results, finding summary, and dataset metadata.

---

## Fields (Verified)

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `source` | Enum | Required | `demo` / `CSV` / `XLSX` / `connector_future` |
| `status` | Enum | Required | `draft` / `running` / `completed` / `failed` / `archived` |
| `healthScore` | Number | 0–100 | Composite overall score |
| `dataQualityScore` | Number | 0–100 | Completeness, consistency, validity |
| `structuralIntegrityScore` | Number | 0–100 | Referential integrity, FKs, orphans |
| `pricingIntegrityScore` | Number | 0–100 | Margin logic, currency, staleness |
| `inventoryIntegrityScore` | Number | 0–100 | Stock accuracy, UoM, valuation |
| `masterDataQualityScore` | Number | 0–100 | Standardization, completeness, format |
| `findingCountsBySeverity` | Object | Required | `{critical: n, high: n, medium: n, low: n, informational: n}` |
| `datasetSummary` | Object | Required | Row counts, column profiles, data types |

## Scoring Model (Verified)

### 6 Dimensions + Weights

| Dimension | Weight | Description |
|-----------|--------|-------------|
| Data Quality | 25% | Completeness, consistency, validity, format |
| Structural Integrity | 20% | Referential integrity, FKs, orphans |
| Pricing Integrity | 20% | Margin logic, currency, staleness |
| Inventory Integrity | 15% | Stock accuracy, UoM, valuation |
| Master Data Quality | 10% | Standardization, completeness, format |
| Database Health | 10% | Schema, indexes, constraints |

### Composite Calculation

```
healthScore = Σ(dimensionScore × weight)
```

Each dimension: 0–100 derived from finding counts by severity/confidence.

### Severity Weights (for dimension scoring)

| Severity | Weight |
|----------|--------|
| `critical` | 10× |
| `high` | 5× |
| `medium` | 2× |
| `low` | 1× |
| `informational` | 0.1× |

### Confidence Multipliers

| Confidence | Multiplier |
|------------|------------|
| `certain` | 1.0 |
| `strong_signal` | 0.7 |
| `suspected` | 0.3 |

## Indexing

- (userId, companyId) — projects per company
- (userId, status) — active project list
- (userId, createdAt) — chronological
- (userId, healthScore) — score sorting

---

## Cascade Behavior

| Event | Effect |
|-------|--------|
| AuditProject archived | Findings → archived (soft) |
| AuditProject deleted | Soft-delete: archive findings, anonymize |
| Score recomputed | On every Finding CRUD (async) |
